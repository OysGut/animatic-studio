# Adobe Marketplace – forberedelse (ikke sendt inn)

Fylles ut i Adobe Developer Distribution når Øystein bestemmer innsending.

| Felt | Utkast |
|---|---|
| Navn | From Pen to Glass |
| Plugin-ID | `com.pentoglass.photoshop` (må registreres i Adobe Developer Console; ID-en i `manifest.json` byttes til den Adobe tildeler) |
| Vert | Photoshop 27.0+ |
| Kort beskrivelse (en) | Open assets and storyboard panels from From Pen to Glass, edit layers in Photoshop and send them back as new candidate versions. |
| Kort beskrivelse (nb) | Åpne ressurser og storyboardpaneler fra From Pen to Glass, rediger lag i Photoshop og send dem tilbake som nye kandidatversjoner. |
| Nettverk | Bare `https://pentoglass.com` |
| Personvern | Lenke til personvernerklæringen på pentoglass.com (må finnes før innsending) |
| Støtte | E-postadresse for støtte (Øystein bestemmer) |

Gjenstår før innsending: ekte ikoner (48/96 px og panelikon 23/46 px), skjermbilder, personvernlenke, sjekklisten i `docs/development/C2_REPORT.md` bestått på macOS og Windows, og at PSD kan lagres som versjon (se rapporten).
